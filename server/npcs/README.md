# NPCs reais (fora do GitHub)

Esta pasta guarda as fichas reais dos NPCs, com **código secreto e respostas**.
O git **ignora** tudo aqui, exceto este README, porque o repositório é público.

- Modelo para copiar: `../npcs_exemplo/informatica_sala1.json` (fictício).
- Nome do arquivo = ID do NPC: `<tema>_sala<n>.json`.
- Como os autores entregam os arquivos: ver "Entrega dos NPCs" em `../README.md`.
